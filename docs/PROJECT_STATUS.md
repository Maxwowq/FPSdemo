## 关键决策

- 使用 C++20、VS Code、CMake 和 Ninja。
- macOS 使用 Apple Clang，Windows 使用 MSVC Build Tools。
- 不使用游戏引擎。
- 图形使用 OpenGL、GLFW 和 GLM。
- 网络阶段优先使用原生 UDP Socket。
- 服务器拥有最终权威。
- 开发过程采用“有脚手架的亲手实现”：先讲最小必要概念，再由用户尝试核心实现，卡住时分级提示，之后共同审查和复盘。
